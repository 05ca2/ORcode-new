# ORcode v0.2.16 — 每岗进度 + 可折叠的推理思考

## 📊 所有智能体都有完成进度

每个岗位行尾实时显示进度：

```
  ○ 指挥 Director  - ▾ · 0/2        ← 父节点: 子智能体完成数
│ ├─   ○ 产品经理 PM  -     · 0%     ← 叶子岗: 百分比
│ ├─   ● 程序员 Coder  m2    · 70%   ← 执行中
```

- **叶子岗**：`待命 0%` → `思考中 35%` → `执行中 70%` → `完成 100%`
- **父节点**：子智能体完成比例（`· 3/11`）
- 子会话窗口顶部还有完整进度条：`[■■■■■■■░░░] 70% · 执行中 · 子智能体 3/11`

## 🧠 推理与思考过程，可折叠展开

**树内（所有 19 岗都支持）**——点岗位**图标**或其**描述行**（`▸`/`▾`）：

```
│ ├─   ● 程序员 Coder  m2    · 70%
│      ▾ 按方案写/改代码
│          🧠 1. 分析任务需求
│          🧠 2. 写代码
│          🧠 3. 自测通过
```

**子会话窗口内**——「🧠 深度思考 (N)」块，**点标题行或按 `t`** 折叠/展开（默认展开）：

```
[■■■■■■■░░░] 70% · 执行中

🧠 深度思考 (3) ▾
   1. 分析任务需求
   2. 写代码
   3. 自测通过

▸ 子会话记录 (N 条)
   ...
```

## 🐛 修复

- **子会话窗口打开时岗位状态被重置**：旧实现会把 status/thought 清空重来，导致窗口里看不到真实进度和思考——改为**复制实时状态**；重复打开已有子标签时也会先用实时状态刷新（`switchSession` 的旧快照不再覆盖真实进度）
- 树行宽自动管理：`◀执行中` 标记与进度放不下时次要后缀依次让位，长标签岗（如「视觉设计师 Visual Designer」）不再溢出面板
- `[子会话]` 文字标记移除（与 ◐ 图标重复，省下的宽度给进度）
