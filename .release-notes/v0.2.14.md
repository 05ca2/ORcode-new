# ORcode v0.2.14 — 每模型子会话窗口（只读）

## 🪟 每个模型都有自己的子会话窗口

点击工作树里**任意一个岗位行**（或 `tab` 选中岗位后按空输入回车）→ 顶部标签栏打开该模型的专属子会话标签页：

```
 1.会话 1 · Claw      ▸2.程序员 Coder · 子会话        [+ 新会话]
```

### 窗口内容（左栏）
```
◈ 子会话窗口 · 程序员 Coder  (m2)  🔒 只读
─────────────────────────────────────────
▸ 子会话记录 (4 条)
  ◆ 单模型调用 · m2
  ▸ 你: 帮我写一个斐波那契函数
    ▸ 响应:
    function fib(n){ return n<2?n:fib(n-1)+fib(n-2); }
▸ 最近思考
  1. …
🔒 只读窗口 — 不可与子模型对话 · Esc 返回主会话
```

- **记录自动归档**：HOR-loop 运行时每个岗位的活动（思考/执行/核查/完成）写进各自子会话；单模型调用的问答按「该模型属于哪个岗位」自动归档（`subKeyForModel` 路由，找不到回退 Director）
- **最近思考**：取自该岗位子会话记录尾部

### 🔒 只读约束（按需求实现）
- 窗口内**键入、回车一律不放行**——不会把消息发给子模型，仅间隔 1.5s 提示一次「子模型会话为只读窗口」
- 输入框占位符：`子会话窗口 · 程序员 Coder — 🔒 只读, 不可与子模型对话 · Esc 返回`
- `Esc` 返回主会话标签；`Ctrl+W` 可关闭子标签

### 交互细节
- **重复打开聚焦已有标签**，不重复创建；从存储刷新显示（离开期间的新活动可见）
- 关闭子标签后记录仍保留在 `state.subSessions`，再次打开内容还在
- 工作树中当前子会话对应的岗位行显示 `◐ [子会话]` 标记；树底部提示「子会话中 · Esc 返回主会话」
- 没有主会话标签时 `Esc` 会把当前子标签转正为主会话

- 原来的「岗位子会话」是接管主窗口且**可以**直接指挥该岗位模型；现在改为**独立标签页 + 只读**。如需临时指挥某个模型，用 `/models` 切换初始模型后在主会话对话即可。
