# ORcode v0.2.8 — 读取上限可配置

## 📖 模型文件读取上限提升 + 可配置

- 文件大小上限 **1MB → 10MB**（默认），单次读取字符 **4000 → 20000**（默认）
- 全部可在**设置面板**调整：
  - `<` `>` 调整文件大小上限（MB，1-100）
  - `;` `'` 调整单次字符上限（2k-200k）
- 新增 `/readlimit <MB>` 快捷命令，随时查看/设置
- 配置持久化在 `config.json` 的 `maxFileReadSize` / `maxFileReadChars`，旧配置自动补齐
- 非法配置值自动回退默认
