# ORcode v0.2.11

## ✨ 自适应换行（文字全部显示）

- 历史日志按左侧面板可用宽度**自动折行**：长路径（如 `D:\Claw\学习\School\...`）、模型长答复不再被右边界截断
- 折行按**显示宽度**计算：中文/全角字符占 2 列，中英混排不切坏
- ANSI 色码原样保留、不计宽度；续行自动跳过行首空格
- 对话历史上限 200 → **600 条**（折行后也够存）

## 🌐 联网搜索

- 模型新工具块：`<<<SEARCH {"query":"搜索词","reason":"原因"} SEARCH>>>`
  - 真实联网（DuckDuckGo lite，**无需 API Key**），返回标题/链接/摘要（最多 8 条）
  - 与 READ/LIST 一样进入 5 轮工具循环，结果以 `[文件结果]` 回传
- 用户命令：`/search <搜索词>` 直接在 TUI 里搜
- 搜索失败（断网/限流）会明确报错回传给模型，不会静默失败

## 🗄 存档功能增强

- `/archive`（原有）：手动把当前会话导出为 Markdown 到工作区
- **新增 · 自动存档**：关闭会话标签（`Ctrl+W` / `/close`）时，有对话内容的会话先自动落盘再关闭
- **新增 · `/archives`**：列出工作区最新 10 份存档（大小 + 修改时间）
- 存档文件名含**毫秒**，同秒多次存档不再互相覆盖

## 🧪 质量

- 新增 35 项测试（`test-wrap-search-archive.js`）：换行宽度/宽字符/ANSI、SEARCH 解析、DDG HTML 解析（uddg 还原/实体解码/去重/limit）、存档内容/自动存档/空会话不存档
- 全套 **229/229** 通过
- 版本号统一 0.2.11（package.json / orcode.cjs / tui.js / README）
